Sisyphus macOS menu bar icons

These assets are cropped from the original generated concept sheet, not redrawn.
Folders: classic/ and low-profile/
PNG sizes: 16x16, 18x18, 20x20, 22x22; each has a transparent background.
*-master-crop.png contains the original high-resolution crop for reference.

The icons are monochrome black template-style artwork. For native macOS use, mark the image as a template image (e.g. NSImage.isTemplate = true) so macOS can adapt it to the menu bar appearance.

Note: the original is a raster concept sheet, so these are resized raster crops, not vector originals. Inspect the 16 px version in-app before shipping.
